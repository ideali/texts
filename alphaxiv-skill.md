# AlphaXiv — Claude Skill для разбора статей

**Ссылка:** https://www.alphaxiv.org/skills/alphaxiv-paper-lookup/SKILL.md

## Зачем

Не нужно загружать 40-страничные PDF в Claude. Скилл тянет структурированный обзор статьи через API вместо парсинга сырого PDF.

- Пропускает сложные уравнения и таблицы
- Возвращает: проблему, подход, ключевые результаты
- Разобраться в статье за секунды

## Как работает

1. Извлекает arXiv ID из любой ссылки или текста
2. Запрашивает API для получения уникального идентификатора версии
3. Загружает готовый машиночитаемый структурированный обзор

Модель никогда не трогает сырой PDF — получает чистые, преструктурированные данные. Поэтому вывод точнее, чем при обычном промпте на суммаризацию.

## Итог

Раньше понять, стоит ли читать статью — значило её читать.
Теперь сначала получаешь структурированный разбор, потом решаешь, нужны ли тебе все 40 страниц.
